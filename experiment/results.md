# Linear regression vs. local LLM + RAG

Generated by `experiment/run_experiment.py`. Chat model `gemma3:4b` (temperature 0), embedding model `nomic-embed-text`, top-k = 4.

## Data

Task: predict a body's orbital period (Earth years) from its mean distance from the Sun (AU).
Values come from the FAST FACTS tables of `nasa_solar_system_lithographs_2013.pdf` (page in `source_page`). Kilometres are converted to AU with 1 AU = 149.6 million km and days to years with 1 year = 365.26 days, both taken from the Earth sheet of the same PDF. The row `Hypothetical body` is synthetic: its period is 15^1.5 (Kepler's third law).

## Split

Train (7): Mercury, Venus, Earth, Jupiter, Saturn, Neptune, Pluto.
Test (3): Mars, Uranus, Hypothetical body.
Test rows are used for nothing except computing errors. The retrieval collection holds one document per train body plus one background note; the script asserts that no test body or test period is in it.

## Method

- Log-log regression: scikit-learn `LinearRegression` on log10(distance) -> log10(period), train rows only, predictions converted back with 10^x.
- Raw regression: `LinearRegression` on the untransformed values, as a baseline.
- LLM + RAG: Chroma collection (cosine, `nomic-embed-text` embeddings). The query states only the distance; the top 4 documents go into the prompt and the LLM returns one number (structured output). The body is never named.
- LLM, no RAG: the same prompt without reference examples.
- The LLM gets no regression model, no coefficients and no code execution.

## Regression fit (train rows only)

| model | slope | intercept |
| --- | --- | --- |
| log10(period) = slope * log10(distance) + intercept | 1.4998 | -0.0001 |
| period = slope * distance + intercept | 6.2399 | -11.9006 |
